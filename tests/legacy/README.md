# Legacy regression fixtures (v1.0.0 outputs; not a reference for per-event results)

This directory retains fixtures that document the behavior of
`red2400-toolkit v1.0.0` (the mint-pooled dispatch). They are preserved
so anyone reproducing v1-era artifacts can verify that
`classify_dataset(mode='mint_summary_LEGACY_defective')` still reproduces
the historical output byte-for-byte.

They are not independent oracles and they do not show per-event
results. In particular:

- `expected_outputs_v1_defective.json` was generated by
  `scripts/generate_expected_outputs.py` (v1.0.0), which called the
  production `run_audit()` on the real deposit and serialised its
  result. The file locks the implementation to its own past output —
  including the token-level pooling under which the 95.5% of RED-2400
  v2 events on repeat mints received a pooled per-mint trajectory (see
  `CHANGELOG.md`, "v1.0.0 to v2: what changed" and the 2.0.0 entry,
  section "Effect on results", for the details and the numbers).

## What is used from this file

The test `test_audit_runner.py::test_legacy_mode_reproduces_v1_defective_numbers_on_real_deposit`
runs under `mode='mint_summary_LEGACY_defective'` when the real deposit is
available (`RED2400_DEPOSIT_DIR` env var set) and confirms that the
legacy dispatch still produces the historical numbers. That is a
regression witness only.

## What is not used from this file

- No test compares the corrected v2 event-level output against this
  fixture. Corrected outputs will legitimately differ.
- The numbers in this file are token-pooled, not event-level
  results; cite v2 outputs instead.

## Where the per-event reference lives

The per-event comparison target is:

- `tests/conftest.py::ADVERSARIAL_HAND_TABLE` — the hand-computed
  expected tier for every event in the adversarial fixture.
- `tests/oracle.py` — an independent Python implementation of the
  five-tier rule written from the paper spec (no import of
  `red2400_toolkit`).

Tests in `tests/test_classifier_event_level.py` compare the toolkit,
the oracle, and the hand table on every event of the adversarial
fixture. That triangulation is the correctness gate — not this
directory.
