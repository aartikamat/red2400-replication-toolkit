# Getting Support

## Where to ask questions

- **Usage questions** ("how do I run this on my deposit?"): open a
  GitHub issue with the `question` label. Include your Python version,
  the toolkit version, and the exact command you ran.
- **Bug reports**: open a GitHub issue with the `bug` label. Include a
  minimal reproducer.
- **Scientific-correctness concerns**: open a GitHub issue with the
  `scientific-correctness` label. These are treated as top priority.
- **Security issues**: see `SECURITY.md` — please do not open a public
  issue.
- **General discussion / non-defect ideas**: use GitHub Discussions if
  enabled on the repository; otherwise open an issue with the
  `discussion` label.

## Response expectations

This is a single-maintainer project. Response times:

- Scientific-correctness reports: acknowledged within 5 business days,
  triaged (accept / need-more-info / not-a-defect) within 10.
- Bug reports: acknowledged within 10 business days.
- Usage questions: best-effort; expect longer response times.

## Contact for security or coordinated disclosure

See `SECURITY.md`. Use the maintainer email listed there for private
communication only. Publicly reported non-sensitive issues will receive
faster attention on GitHub.

## Not supported

- Custom analysis on private datasets: this project is a replication
  toolkit for the RED-2400 benchmark; it is not a consulting service.
- Live-market advice: the toolkit computes observational classifications
  after-the-fact; it does not produce trading recommendations.
